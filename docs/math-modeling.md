# 用 Agent 做数模，从这一条开始

**已有可用的 Codex CLI：直接看[安装与开打](coding-agent.md)。** 本项目已用固定版 MathModelAgent 技能链完成一份2024国赛B历史题，公开了17页论文、代码和复现材料。

只有 Codex 桌面版、没有用过终端的同学，先看教程开头的[准备条件卡](coding-agent.md#先检查你现在能不能跑)。桌面版已登录不等于终端命令已就绪。

## 默认路线：准备好，再给题

1. 按[安装与开打](coding-agent.md)建独立工作区，先做不调用模型的预检。
2. 放入完整题面与附件，启动 `$1start-mathmodel`。第一次使用历史题，先验证整条流程。
3. 打开 `paper/main.pdf`，核对下面五项。卡住时沿用原工作区恢复，不重新造一套项目。

[先看实际17页成品](../examples/cumcm2024b/paper/main.pdf) · [看实际运行与费用记录](../examples/cumcm2024b/README.md) · [只重算现有成果](../examples/cumcm2024b/README.md#复现计算)

本例CLI两次运行时长合计35.52分钟，包含额度中断后的恢复；停顿、环境准备、外部审计与打包另计。没有单次账单，不据此估算你的费用或完整备赛时间。

## 更想用现成界面

看[Modex官方详细教程](modex.md)：Windows安装、模型连接、工作流、恢复和导出。本项目按官方资料整理，未安装实测。Claude Code可加载同一套技能，但本项目没有做Claude端到端运行；兼容入口在[完整教程](coding-agent.md#其他coding-agent入口)。

## 读到“完成”之后检查什么

- 每个子问题都有模型、能运行的代码和数值结果。
- 图表来自本次计算，论文数字能在结果文件中找到。
- 空目录能重跑，PDF确实编译并逐页检查。
- 缺少真实样本时标明条件或假想演示，不能补成实测。
- 程序枚举固定策略，不等于解决所有可能的自适应策略。

历史题复现不是正式比赛提交，也没有因此获得奖项。[国赛赛事卡](contests/N22.md)单列当届资格、工具范围和奖项路径；其他杯赛不可直接套用。
