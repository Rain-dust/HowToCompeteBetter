# 2026-11-17：阅读体验改进与验收

本页按版本保留阅读体验改进记录，没有新增参赛胜率调查，也没有把二手材料变成独立获奖证据。

## v0.5.0：按问题阅读的十章结构

参考[高性价比人生指南](https://github.com/eternity4719/HowToLiveBetter)的首页与编号章节框架，建立十章正文、57个小节。首页集中放下载与查阅入口，再以问题导航和章节目录进入正文；前五GitHub和指令保留，长任务分别展开。

每章统一为结论、章内目录、操作条目、前后章导航。73张赛事卡由宽表改成“说人话、适合谁、交什么、人要做什么、投入、开打、依据”的固定条目。新术语表解释Agent、Skill、奖级与学校认定的差别。

PDF与仓库使用同名十章，30页含40个层级书签、56处内部跳转。GitHub Markdown实际渲染与390px浏览检查通过；教程搬到章节后的工作目录指代已修正，复制前的本地仓库前提已补齐。

## 维护入口

`data/competitions.json` 是赛事事实源。`ranking.json`、`top5.json`是兼容视图；赛事卡、目录、首页、离线筛选和PDF均由生成脚本读取该源。`data/chapters.json`定义章节、问题和小节，`book/`从原有教程与赛事事实生成，README读取相同的章节配置。

~~~text
python scripts/build_all.py
python scripts/check_reader.py --pdf
~~~

检查覆盖字段、27个唯一名次映射、本地链接与锚点、SVG结构、模板ZIP、合成练习和原数模论文hash。离线阅读页另做真实浏览器的搜索/组合筛选/无结果/键盘/390px布局检查；PDF另渲染逐页看。

成本与正式许可仍可能待核。这一轮解决的是怎样找答案、辨明未知、开始做和防止版本分叉，不把缺失资料写成确定结论。
