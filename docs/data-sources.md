# 比赛数据去哪里找

**先找原表，再让 Agent 清洗、分析、画图。不要让它替你编用户、问卷和营业额。**

[开赛打法](competition-playbook.md) · [交付与答辩](project-delivery.md) · [来源台账模板](../templates/contest-starter/data-provenance.csv)

浪尖知识库提示了宏观、地理、企业与行业数据的查找方向。本页重新核了入口，下面是本项目筛选的落点；核查日期为2026-11-16。**读到入口，不代表已下载数据或取得再分发许可。**

| 要什么 | 先去哪里 | 给 Agent 的具体任务 | 读数前检查 |
| --- | --- | --- | --- |
| 国内人口、产业、地区指标 | [国家统计局](https://www.stats.gov.cn/) / [国家数据](https://data.stats.gov.cn/) | 按变量、地区和年份列取数清单；用原表做清洗脚本，保留指标解释 | 单位、统计口径、现价/不变价、行政区划变化；国家数据需浏览器JS |
| 跨国发展指标 | [World Bank Open Data](https://data.worldbank.org/) | 按指标代码提取国家-年份表，保留缺失值、来源与更新时间 | 同一指标定义、汇率/购买力口径；不要把缺失补成0 |
| 联合国体系指标 | [UNdata / UN System Data Commons](https://data.un.org/) | 先定位发布机构与原始数据集，再整理变量和脚注 | 平台已使用JS页面；不能照旧博客虚构可用API |
| 环境、土地、空间数据 | [国家地球系统科学数据中心](https://www.geodata.cn/) | 搜具体区域与时间分辨率，记录数据集DOI/引用方式，再做裁剪和单位转换 | 下载条件、坐标系、分辨率、年份；实际数据集许可另核 |
| 资源环境专题目录 | [资源环境科学数据平台](https://www.resdc.cn/) | 先找到匹配数据集及申请条件；拿到获准文件后才写处理流程 | 本轮只读到入口，未测试申请/下载，不承诺免费 |
| 企业年报、公告和经营事实 | [巨潮资讯网](https://www.cninfo.com.cn/) | 定位具体公告PDF，抽表并回看页码；区分历史实绩和公司预测 | 合并/母公司口径、人民币单位、年度；不把单家公司当整个市场 |

**行业报告和搜索指数怎么用：** 可以用来发现关键词、竞品和待验证问题。追到原始发布者、年份、样本与方法，再决定能否引用。搜索热度不是销量，问卷意愿不是付费，第三方估算不是你的真实经营数据。

## 数据给 Agent 前，至少保留这几列

模板：[data-provenance.csv](../templates/contest-starter/data-provenance.csv)。每个数据文件写清：

`data_id → 发布者 → 原始URL → 表号/页码 → 数据期 → 获取日期 → 单位/口径 → 使用条件 → 文件SHA256 → 清洗脚本 → 对应图表`

清洗后的文件放 `data/processed/`，原始文件放 `data/raw/`。不要手动覆盖原表；小数、百分比、万元/元和区域合并都留转换记录。

## 直接复制给 Codex

~~~text
请整理当前项目的数据，不先训练复杂模型。读取 data/raw/ 和 inputs/ 的问题定义。
为每份原始数据补 data-provenance.csv：发布者、原始URL、表号/页码、数据期、获取日、单位、使用条件与文件SHA256。缺来源的标待核，不猜。
写可重复运行的清洗流程，检查缺失、重复、单位、时间穿越、目标泄漏、训练测试交叉和行政区划变化；原始文件保持只读。
先做一个简单基线和一张关键图，图注能追到 data_id 与生成脚本。没有真实样本时，只能用明确标注的合成数据调试，不能把模拟包装成调研。
交付原始到结果的文件清单、数据字典、实际运行日志、问题列表和复跑命令。
~~~

做问卷或访谈时，另外保留招募方式、调查期、回收/剔除口径和知情使用范围；公开资料不自动等于可公开个人明细。正式统计建模赛还要先核[当届核心内容限制](top5-start.md#4-全国大学生统计建模大赛)。
