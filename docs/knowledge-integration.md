## 补充的5个入口

这5项补进[72条选赛参考](competition-catalog.md)，**不强行插入主榜1–27**。它们来自新增线索和官方核对，缺少本项目要求的Agent参赛结果证据；制作适配与正式工具许可分别写。以下为编辑判断，不是实测胜率。

| 入口 | 一句话结论 | 先怎么打 |
| --- | --- | --- |
| **中国大学生计算机设计大赛（高职高专）** | 高职学生优先研究软件/AI作品；本科榜的资格和工具规则不能直接套 | 先读高职当届通知；练习可复用[开发技能与测试](top5-start.md#2-中国大学生计算机设计大赛)，做一个可运行核心功能 |
| **中青杯全国大学生数学建模竞赛** | 可以做数模链迁移练习；没核到完整AI许可，不写“可直接交AI成稿” | 用[已验证的数模链](coding-agent.md)跑历史题；另核学校认定和当届规则 |
| **“学创杯”全国大学生创业综合模拟大赛** | 是专用经营模拟平台，不是做一份BP就交；暂不主推Agent全程代打 | 获取训练账号，先学平台规则，再用导出记录做策略复盘；不擅自自动操作正式赛客户端 |
| **CIMC“西门子杯”中国智能制造挑战赛** | 只筛软件/仿真相关方向；平台、PLC与现场条件可能才是大头 | 先跑官方练习环境，量化设备和软件成本；有同环境基线再做优化 |
| **世界职业院校技能大赛（重点关注AI赛道）** | 2026有普通本科可参加的特定赛道，但核心是现场技能展示 | 先核学校推荐资格和组别；把AI产品做成能现场讲、现场操作的真实项目 |

### 当届依据

- 高职计设：2026第4届分6个大类，另设企业赛道；与本科第19届分开。[校方通知](https://it.hceb.edu.cn/info/1053/25691.htm)、[2026决赛信息](https://www.shanghai.gov.cn/nw15343/20260826/45f8f2a0b59a44928dfed0e89024876a.html)。高职完整外部Agent许可未核到。
- 中青杯：已读到2026第八届官方发布页；附件及完整AI细则未成功读取，费用、当届许可和学校认定不补写。[官方通知入口](https://zqb.52jingsai.com/newss.php?id=42)。
- 学创杯：2026第十三届有创业综合模拟、数字营销模拟、财务决策模拟三项，使用专用客户端；财务赛项有专业要求。[西安交大组织通知](https://dean.xjtu.edu.cn/info/1172/10073.htm)。各校报名、推荐和分组不同，不能照搬该校截止时间。
- 西门子杯：2026当届通知区分线下赛项与线上评审赛项；“仿真”不自动等于不需要设备或可以外部Agent代打。[组委会初赛通知](https://www.siemenscup-cimc.org.cn/notice/NoticeDetail?id=2432)、[参赛说明](https://www.siemenscup-cimc.org.cn/joinflow/index)。
- 世界职业院校技能大赛：2026教育部方案设43个赛道，项目要技能操作与讲解；普通本科可参加人工智能、中华传统技艺等方案指定范围，学校推荐和实际组别另核。[2026实施方案](https://www.moe.gov.cn/srcsite/A07/s7055/202608/t20260820_1447374.html)。

这些入口的2026资料用于辨认赛事与备赛条件，不表示当前仍开放报名，也不推断2027沿用原规则。

## 没有照单全收的内容

| 整理资料中的说法 | 本项目采用的口径 |
| --- | --- |
| “教育部2025年正式发布84项” | 追溯到中国高等教育学会《2023全国普通高校大学生竞赛分析报告》的历史目录口径；不能推出教育部全国统一ABC。可对照[高校说明](https://www3.xzmu.edu.cn/jwc/getcontent?id=101858&url=show)与本项目[原来源](sources.md) |
| 国赛通常10–11月、统一9月报名，另处又写9月赛 | 2026正式赛为9月10日18时至13日20时，共74小时；校内报名可能早很多。[赛事官网](https://www.mcm.edu.cn/)、[中科大当届报名通知](https://math.ustc.edu.cn/2026/0520/c18650a741197/pagem.htm) |
| 职业技能大赛沿用2025年42赛道与旧时间表 | 改按2026教育部43赛道方案，报名系统为方案所列入口；具体学校和省级流程另核 |
| 大创也算一场比赛；同项目投多个赛天然可行 | [大创是训练计划](https://www.moe.gov.cn/srcsite/A08/s5672/201907/t20190724_392132.html)，立项/结题与竞赛奖项分开；复用逐项查规则 |
| 匿名访谈、融资数字、培训保奖和退费承诺 | 只作为二手线索，不进独立成功案例、获奖率、费用或商业推荐；不把口播当证书核验 |
| 找到原稿/好PPT就能复刻成参赛材料 | 学习结构和表达，实际数据、代码、图片、结果与贡献使用自己的获准内容；不搬课程模板或他人成果 |

## 来源类型为什么单列

同一个知识库的多个第一人称文章，不能直接算多个独立学生；直播转写也可能漏画面、识别错名称。**原来的75篇社会反馈、16篇亲历/个人经验筛选和22份外部材料，统计保持不变。** 本轮另建“知识整理”台账，主榜不因二手数量变多而自动升降。

优先参阅台账中的：LJ05成果转化、LJ06组队、LJ08数据、LJ09答辩、LJ10文书、LJ27/29学校资源与项目路径、LJ30自荐。LJ35含RST培训推介，不能拿它给“Agent获奖”补闭环。
