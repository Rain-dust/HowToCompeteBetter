# 这份参考顺序怎么读

**先看“当届怎么选”，再看制作参考序号。** 序号保持1–27连续显示；它不替代参赛资格、AI许可、报名状态或本校奖项认定。

[回首页](../README.md) · [按条件找比赛](competition-catalog.md)

## 为什么保留这个顺序

这是项目积累的制作适配编辑顺序。排序主要考虑：

1. **能交什么**：软件、计算、图表、论文等工作能否形成可复现的完整成果。
2. **有什么依据**：作者历史经历、外部参赛复盘、实际工具运行与反例；各自支持范围分开。
3. **还缺什么**：数据、设备、平台、真实用户、核心判断和现场能力等人工门槛。

当前证据不足以支持“第4名一定比第6名更划算”这样的精细比较。因此序号用于定位和浏览，不是经过统计测量的性价比总分；项目不制造胜率、加权分或保奖结论。

## 真正选正式赛时，先执行这些条件

| 条件 | 你需要得到的答案 |
| --- | --- |
| 身份 | 具体赛项接受你的学历、学籍、专业与组队方式吗？ |
| 工具范围 | 当届允许你计划执行的AI任务和工具吗？核心生成受限时不使用全流程直出提交 |
| 奖项路径 | 有你需要的省级/赛区/全国阶段吗？实际证书怎样被本校认定？ |
| 资源 | 数据、设备、接口、训练平台、队友和指导能拿到吗？ |
| 投入 | 人数、时间、报名费、模型费、设备和主要人工任务能承受吗？未知项先补核 |

未过条件时，排在前面也不能直接报名或提交。历史题练习仍可用于学习和检查工具链。

## 两个容易误读的例子

- **统计建模参考第4**：数据与计算制作很适配，但已核2026规范限制核心设计与正文直出，不能据此推荐全程Agent参赛。
- **计设参考第2**：保留作者历史Codex省奖经历，但2026限定工具名单，外部Codex许可未核，旧经历不能覆盖当届规则。

赛事卡把“制作参考”“当届建议”“证据状态”分开显示；报名入口未确认就标待核，不以规则PDF冒充报名。

## 验证状态如何理解

| 标记 | 能说明什么 |
| --- | --- |
| 历史题已跑通 | 该环境和固定技能链产出过可复现成果，不等于参赛获奖 |
| 作者历史亲历 | 项目作者自述，未给出的届次和具体杯赛不补写 |
| 外部参赛自述 | 可参考过程和卡点，不当作证书、身份与获奖概率认证 |
| 官方资料教程 | 安装与步骤按已读官方说明整理，不冒充本机运行 |
| 权限/费用待核 | 尚缺足够依据，不能因为存在链接就当作已获准或免费 |

未知项保留未知。选择建议使用带日期的当届依据，下一届重新核对。
