# 已填练习输入卡

- 用途：practice，自拟数据处理教学练习；不对应某届比赛。
- 比赛、学校认定、报名、工具许可：不适用；将来正式参赛需另外填写。
- 用户和问题：练习把一个小CSV整理成可核对结果；没有真实用户或调研。
- 输入：`data/raw/tickets.csv`，15条作者编写的合成工单。
- 字段：`ticket_id`是练习编号，`category`是地点类别，`response_minutes`是合成的响应分钟数。
- 规则：重复编号、缺地点、缺分钟、非数值分钟或负分钟进入剔除表；其他行进入汇总。
- 第一版交付：汇总CSV/JSON、剔除表、带合成标识的SVG、中文报告和检查结果。
- 第一版预期：15条输入、10条有效、5条剔除；有效时长合计450分钟。
- 数据来源：本项目作者编写的固定合成数据。没有下载、问卷、设备、接口或个人信息。
- 环境与费用：Python标准库；脚本不联网、不调用模型、不读取密钥。
- 人工任务：核对输入与结果，明确练习用途；没有真实学生或团队署名。
- 已知限制：无随机抽样、无真实场景代表性；不推出真实服务效率或因果关系。
