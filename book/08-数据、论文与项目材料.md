## 8.1 第一次做完整项目：先跑零依赖小样例

还没做过完整项目，先跑这个小样例。它使用仓库内的**合成工单数据**，不调用模型、不联网取数，也不需要密钥。

在仓库根目录执行：

~~~text
python templates/contest-starter-example/run.py
~~~

你会得到汇总表、清洗拒绝记录、图表、报告与验收记录：输入 15 行、保留 10 行、拒绝 5 行，总时长 450 分钟。这个数字来自固定练习数据，不是学校业务数据或参赛成绩。

先打开[已填样例说明](../templates/contest-starter-example/README.md)核对输出，再复制[空白项目模板](../templates/contest-starter/README.md)放自己的题目与数据。[下载两个模板 ZIP](../templates/contest-starter.zip)。

## 8.2 原始数据先从哪里找

以下入口沿用 2026-11-16 的资料核查。先定位具体原始表，再核下载条件与使用范围；入口可见不表示已经拿到数据。

### 1. 国内人口、产业、地区指标

**入口：** [国家统计局](https://www.stats.gov.cn/) / [国家数据](https://data.stats.gov.cn/)

**交给 Agent：** 按变量、地区和年份列取数清单；用原表做清洗脚本，保留指标解释

**读数前检查：** 单位、统计口径、现价/不变价、行政区划变化；国家数据需浏览器JS

### 2. 跨国发展指标

**入口：** [World Bank Open Data](https://data.worldbank.org/)

**交给 Agent：** 按指标代码提取国家-年份表，保留缺失值、来源与更新时间

**读数前检查：** 同一指标定义、汇率/购买力口径；不要把缺失补成0

### 3. 联合国体系指标

**入口：** [UNdata / UN System Data Commons](https://data.un.org/)

**交给 Agent：** 先定位发布机构与原始数据集，再整理变量和脚注

**读数前检查：** 平台已使用JS页面；不能照旧博客虚构可用API

### 4. 环境、土地、空间数据

**入口：** [国家地球系统科学数据中心](https://www.geodata.cn/)

**交给 Agent：** 搜具体区域与时间分辨率，记录数据集DOI/引用方式，再做裁剪和单位转换

**读数前检查：** 下载条件、坐标系、分辨率、年份；实际数据集许可另核

### 5. 资源环境专题目录

**入口：** [资源环境科学数据平台](https://www.resdc.cn/)

**交给 Agent：** 先找到匹配数据集及申请条件；拿到获准文件后才写处理流程

**读数前检查：** 本轮只读到入口，未测试申请/下载，不承诺免费

### 6. 企业年报、公告和经营事实

**入口：** [巨潮资讯网](https://www.cninfo.com.cn/)

**交给 Agent：** 定位具体公告PDF，抽表并回看页码；区分历史实绩和公司预测

**读数前检查：** 合并/母公司口径、人民币单位、年度；不把单家公司当整个市场

行业报告和搜索指数可以帮助找关键词，但引用时要追到原始发布者、年份、样本与方法。搜索热度不是销量，第三方估算也不是自己的经营数据。

## 8.3 数据给 Agent 前，至少保留这几列

模板：[data-provenance.csv](../templates/contest-starter/data-provenance.csv)。每个数据文件写清：

`data_id → 发布者 → 原始URL → 表号/页码 → 数据期 → 获取日期 → 单位/口径 → 使用条件 → 文件SHA256 → 清洗脚本 → 对应图表`

清洗后的文件放 `data/processed/`，原始文件放 `data/raw/`。不要手动覆盖原表；小数、百分比、万元/元和区域合并都留转换记录。

## 8.4 直接复制给 Codex

~~~text
请整理当前项目的数据，不先训练复杂模型。读取 data/raw/ 和 inputs/ 的问题定义。
为每份原始数据补 data-provenance.csv：发布者、原始URL、表号/页码、数据期、获取日、单位、使用条件与文件SHA256。缺来源的标待核，不猜。
写可重复运行的清洗流程，检查缺失、重复、单位、时间穿越、目标泄漏、训练测试交叉和行政区划变化；原始文件保持只读。
先做一个简单基线和一张关键图，图注能追到 data_id 与生成脚本。没有真实样本时，只能用明确标注的合成数据调试，不能把模拟包装成调研。
交付原始到结果的文件清单、数据字典、实际运行日志、问题列表和复跑命令。
~~~

做问卷或访谈时，另外保留招募方式、调查期、回收/剔除口径和知情使用范围；公开资料不自动等于可公开个人明细。正式统计建模赛还要先核[当届核心内容限制](../docs/top5-start.md#4-全国大学生统计建模大赛)。

## 8.5 先有计算结果，再写论文与项目材料

把“来源 → 清洗 → 计算 → 图表 → 正文”连成一条能复查的链。正文中的每个关键数字能指回结果文件；图表能指回生成脚本；外部事实能指回原始来源。

~~~text
先读取完整题面、评分表和来源台账。保留原始文件，只在工作副本上清洗；输出缺失、重复和拒绝记录。
每张图记录输入文件和生成脚本，每个关键数字记录结果文件与计算口径。没有数据时明确缺口，不能补写成调查、访谈或实测。
先完成真实计算和复核，再组织论文或项目材料；逐项检查正文数字、图表、代码输出是否一致。
~~~

数模的实际例子见[第 5 章](05-从真题看完整成果.md)。项目书、商业计划书、论文各有不同提交要求，进入[第 9 章](09-演示、答辩与提交.md)再按评分表整理。

## 8.6 统计建模：先看核心生成限制，再决定任务范围

**全国大学生统计建模大赛：正式赛核心生成受限。**

2026禁止AI直接生成核心研究设计与正文；这届不推荐作为Agent全程直出参赛路线。

[完整赛事卡](../docs/contests/N23.md) · 规则资料核查至 2026-11-12

**对应工具仓库**

- [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills)
- [统计分析入口](https://github.com/K-Dense-AI/scientific-agent-skills/tree/main/skills/statistical-analysis)
- [数据检查入口](https://github.com/K-Dense-AI/scientific-agent-skills/tree/main/skills/exploratory-data-analysis)

**复制给 Codex：安装与预检**

~~~text
请从 https://github.com/K-Dense-AI/scientific-agent-skills 安装 skills/exploratory-data-analysis 与 skills/statistical-analysis 两个完整目录到当前项目 .agents/skills/，连同引用资源一起保留。按各 SKILL.md 配置独立 Python 环境，不安装无关科学栈。用本地合成CSV完成一次有缺失值、重复和分组信息的检查，报告环境、commit与结果。此安装用于赛前练习，不代表获准生成正式参赛核心内容。
~~~

**复制给 Codex：开打**

~~~text
请先读 inputs/ 的全国大学生统计建模大赛当届AI规范。2026正式赛模式只执行规则明确允许的文献检索整理、语言格式校对等环节；不要直接生成研究选题、假设、框架、调查方案或论文正文。把拟执行的数据与代码任务单独列出待核权限。赛前练习模式下，可用 $exploratory-data-analysis 和 $statistical-analysis 对合成/历史练习数据做审计、按已给方案复现与诊断，输出可重跑代码和错误记录。正式提交内容以获准范围和人工原创方案为准。
~~~

**需要交出来：** 练习复现包；正式赛的获准辅助材料、校对意见与AI使用披露。

**你仍需要完成：** 人独立提出研究问题与设计；真实数据和统计解释；核心论文写作与全过程监督。
